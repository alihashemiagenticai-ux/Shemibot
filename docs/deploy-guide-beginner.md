# راهنمای نصب — قدم به قدم، برای کسی که هیچی از این فضا نمی‌دونه

این راهنما رو طوری نوشتم که نیازی به هیچ دانش قبلی نداشته باشید. هرجا یک اصطلاح تازه بیاد، همون‌جا توضیحش می‌دم. کافیه قدم‌به‌قدم پیش برید و هیچ قدمی رو رد نکنید.

**چقدر طول می‌کشه؟** حدود یک ساعت، ولی فقط همین یک‌بار. بعدش ربات همیشه روشنه و خودش کارش رو می‌کنه.

**هزینه؟** صفر تومان، هیچ‌جای این راهنما نیازی به ثبت کارت بانکی ندارید — نه در Cloudflare، نه در تلگرام، نه در متا.

---

## این پروژه اصلاً چیکار می‌کنه؟

فرض کنید یک منشی دارید که ۲۴ ساعته، بدون خستگی، پای دایرکت اینستاگرام‌تون نشسته. هرکس یک پیام خاص (مثلاً «قیمت») بفرسته، منشی فوراً جوابی که خودتون از قبل نوشتید رو می‌فرسته. این پروژه همون منشیه — فقط به‌جای آدم، یک برنامه‌ی کامپیوتریه که رایگان روی سرورهای Cloudflare اجرا می‌شه، و شما از طریق یک ربات تلگرامی بهش می‌گید چیکار کنه.

---

## قبل از شروع، این‌ها رو آماده کنید

1. یک گوشی یا کامپیوتر با اینترنت (ترجیحاً کامپیوتر، چون بعضی قدم‌ها تایپ‌کردن دارن).
2. یک صفحه‌ی اینستاگرام از نوع **کسب‌وکاری (Business)** یا **سازنده‌ی محتوا (Creator)** — نه یک اکانت شخصی معمولی. برای چک‌کردن: توی اپ اینستاگرام برید Settings → Account type and tools. اگه نوشته «Switch to Personal account»، یعنی همین الان کسب‌وکاری/سازنده هست و مشکلی نیست. اگه نوشته «Switch to Professional Account»، روش بزنید و Business یا Creator رو انتخاب کنید (رایگانه، چند ثانیه طول می‌کشه).
3. یک ایمیل که بهش دسترسی دارید.

---

## نقشه‌ی راه

قراره این ۱۰ قدم رو یکی‌یکی انجام بدیم:

1. ساخت حساب GitHub (یک گنجه‌ی آنلاین رایگان برای نگه‌داری کد)
2. کپی‌کردن پروژه به حساب خودتون
3. ساخت ربات تلگرامی‌تون
4. گرفتن شناسه‌ی عددی تلگرام خودتون
5. ساخت حساب Cloudflare (جایی که ربات واقعاً روش اجرا می‌شه)
6. ساخت یک اپ در سایت متا (فیسبوک) — طولانی‌ترین قدمه، ولی فقط یک‌بار
7. نصب نهایی با یک دکمه
8. ثبت وبهوک اینستاگرام (تا پیام‌ها و کامنت‌ها واقعاً به ربات برسن)
9. ساخت کانال خصوصی رسانه در تلگرام
10. وصل‌کردن ربات تلگرام به سرور

بریم سراغش.

---

## قدم ۱ — ساخت حساب GitHub

GitHub جایی‌ست که کد این پروژه اونجا نگه‌داری می‌شه. برای این‌که نسخه‌ی خودتون رو داشته باشید، اول باید یک حساب GitHub بسازید (اگه از قبل دارید، این قدم رو رد کنید).

1. برید به [github.com](https://github.com)
2. روی «Sign up» بزنید
3. ایمیل، رمز عبور، و یک نام کاربری وارد کنید
4. مراحل تأیید (ممکنه یک کد به ایمیل‌تون بفرسته) رو کامل کنید

✅ وقتی وارد صفحه‌ی اصلی GitHub با نام کاربری خودتون بالای صفحه شدید، این قدم تمومه.

---

## قدم ۲ — کپی‌کردن پروژه به حساب خودتون (Fork)

«Fork» یعنی یک کپی از این پروژه رو ببرید توی حساب خودتون، تا مال خودتون باشه و بتونید تغییرش بدید.

1. وارد این لینک بشید: **[github.com/alihashemiagenticai-ux/Shemibot](https://github.com/alihashemiagenticai-ux/Shemibot)**
2. بالا-راست صفحه، دکمه‌ی «Fork» رو بزنید
3. صبر کنید چند ثانیه، و «Create fork» رو بزنید

✅ حالا یک کپی از پروژه، زیر نام کاربری خودتون در GitHub دارید.

---

## قدم ۳ — ساخت ربات تلگرامی‌تون

1. تلگرام رو باز کنید و در قسمت جستجو بنویسید: `BotFather`
2. روی اکانتی که تیک آبی داره بزنید (همون ربات رسمی تلگرام برای ساخت ربات‌های دیگه)
3. بزنید Start
4. بنویسید: `/newbot`
5. یک اسم دلخواه براش انتخاب کنید (مثلاً «دستیار دایرکت من»)
6. یک یوزرنیم دلخواه انتخاب کنید — باید به `bot` ختم بشه (مثلاً `MyDirectAssistantBot`)
7. BotFather یک پیام طولانی برمی‌گردونه که توش یک رشته‌ی عجیب هست شبیه این:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   این «توکن ربات» شماست. **این رو کپی کنید و یک‌جای امن (مثلاً یادداشت گوشی) موقتاً ذخیره کنید** — بعداً لازمش داریم.

⚠️ این رشته رو برای هیچ‌کس نفرستید — هرکسی که این رو داشته باشه می‌تونه جای شما ربات رو کنترل کنه.

---

## قدم ۴ — گرفتن شناسه‌ی عددی تلگرام خودتون

ربات باید بدونه که فقط شما (و نه هرکس دیگه‌ای) اجازه دارید بهش دستور بدید. برای این کار به شناسه‌ی عددی حساب تلگرام‌تون نیاز داریم.

1. در تلگرام جستجو کنید: `userinfobot`
2. بزنید Start
3. یک عدد بهتون نشون می‌ده (مثلاً `987654321`) — این شناسه‌ی شماست
4. این عدد رو هم جایی یادداشت کنید

---

## قدم ۵ — ساخت حساب Cloudflare

Cloudflare همون سروریه که ربات شما ۲۴ ساعته روش روشنه — کاملاً رایگان، بدون نیاز به کارت بانکی.

1. برید به [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)
2. ایمیل و یک رمز عبور وارد کنید
3. ایمیل‌تون رو طبق لینکی که براتون می‌فرسته تأیید کنید

✅ وقتی وارد داشبورد Cloudflare شدید، این قدم تمومه.

---

## قدم ۶ — ساخت یک اپ در سایت متا (فیسبوک)

این تنها قدمیه که واقعاً کمی طول می‌کشه (حدود ۲۰ دقیقه)، چون باید توی سایت خودِ متا (فیسبوک) چندتا تنظیمات دستی انجام بدید — این بخش رو هیچ برنامه‌ای نمی‌تونه براتون خودکار کنه، چون تصمیم خود متاست که این کار دستی باشه (برای امنیت بیشتر).

راهنمای کامل این قدم رو جدا نوشتم، چون خودش چند مرحله داره: **[docs/facebook-app-setup.md](facebook-app-setup.md)**

وقتی اون راهنما رو کامل کردید، این ۳ چیز رو باید داشته باشید (یادداشت‌شون کنید):
- Instagram App ID (یک عدد)
- Instagram App Secret (یک رشته‌ی حروف و عدد)
- یک توکن دسترسی برای پیج اینستاگرامی‌تون (که در همون راهنما توضیح داده چطور بگیریدش)

سپس برگردید به همین‌جا و برید سراغ قدم ۷.

---

## قدم ۷ — نصب نهایی با یک دکمه

این قسمت جادویی‌ترین قسمته: با زدن یک دکمه، همه‌چیز خودکار روی حساب Cloudflare خودتون ساخته می‌شه.

1. برید به صفحه‌ی پروژه‌ی fork‌شده‌ی خودتون در GitHub (همونی که در قدم ۲ ساختید)
2. فایل `README.md` رو باز کنید
3. روی دکمه‌ی آبی‌رنگ «Deploy to Cloudflare» بزنید
4. اگه ازتون خواست وارد Cloudflare بشید، با همون حسابی که در قدم ۵ ساختید وارد بشید
5. یک فرم نشون داده می‌شه که ازتون چند مقدار می‌خواد. این‌ها رو پر کنید:

| این رو می‌خواد | چی بذارید |
|---|---|
| `TELEGRAM_BOT_TOKEN` | همون رشته‌ی طولانی از قدم ۳ |
| `FACEBOOK_APP_ID` | همون عدد از قدم ۶ |
| `FACEBOOK_APP_SECRET` | همون رشته از قدم ۶ |
| `ADMIN_TELEGRAM_ID` | همون عدد از قدم ۴ |
| `IG_WEBHOOK_VERIFY_TOKEN` | هر کلمه‌ی دلخواه خودتون (مثلاً `myVerify123`) — یادتون بمونه، در قدم ۸ دوباره لازمش دارید |

6. دکمه‌ی «Deploy» یا «Create and Deploy» رو بزنید و چند دقیقه صبر کنید

✅ وقتی پیام موفقیت دیدید، ربات شما الان روی اینترنت روشنه! توی داشبورد Cloudflare، برید Workers & Pages → روی پروژه‌ی خودتون بزنید. بالای صفحه یک آدرس می‌بینید شبیه این: `https://shemibot.YOUR-NAME.workers.dev` — این رو یک‌جایی کپی کنید، چون در دو قدم بعدی لازمش دارید.

---

## قدم ۸ — ثبت وبهوک اینستاگرام در App Dashboard متا

تا الان ربات روی اینترنت روشنه، ولی متا هنوز نمی‌دونه پیام‌ها و کامنت‌های جدید رو کجا بفرسته. این قدم دقیقاً همون اتصاله — یک‌بار انجامش می‌دید و تمومه.

1. برگردید به [developers.facebook.com](https://developers.facebook.com) → اپی که در قدم ۶ ساختید
2. توی منوی سمت چپ، دنبال **Webhooks** بگردید (ممکنه زیرمجموعه‌ی محصول Instagram باشه یا یک آیتم جدا در منو — بسته به نسخه‌ی داشبورد)
3. آبجکت **Instagram** رو انتخاب کنید و روی «Edit Subscription» یا «Set up» بزنید
4. این دو مقدار رو وارد کنید:
   - **Callback URL**: همون آدرس Worker از قدم ۷ + `/webhook/instagram` — مثلاً:
     `https://shemibot.YOUR-NAME.workers.dev/webhook/instagram`
   - **Verify Token**: دقیقاً همون رشته‌ای که در قدم ۷ برای `IG_WEBHOOK_VERIFY_TOKEN` وارد کردید
5. روی «Verify and Save» بزنید. متا فوراً یک درخواست تستی به همون آدرس می‌فرسته؛ اگه مقدار Verify Token درست باشه، فوراً تأیید می‌شه (نیازی به صبرکردن نیست)
6. توی لیست فیلدها، این‌ها رو **Subscribe** کنید (فعالشون کنید): `messages`، `comments`، `live_comments`، و `messaging_postbacks` (این آخری فقط لازمه اگه بخواید از قابلیت «فالو اجباری» استفاده کنید — بدونش، دکمه‌ی «فالو کردم» جواب نمی‌ده)

⚠️ **یک قدم دیگه که خیلی راحت جا می‌مونه:** توی خودِ اپ اینستاگرام (نه App Dashboard متا)، با همون اکانتی که به ربات وصل کردید، برید:
`Settings → Messages and story replies → Message controls → Connected tools`
و «Allow access to messages» رو روشن کنید. بدون این تنظیم، حتی اگه وبهوک درست ثبت شده باشه، دایرکت‌ها اصلاً به ربات نمی‌رسن — و هیچ خطایی هم جایی نشون داده نمی‌شه، فقط ربات ساکت می‌مونه.

✅ اگه «Verify and Save» رو بدون خطا رد کردید و فیلدهای بالا تیک خورده‌ان، این قدم تمومه.

---

## قدم ۹ — ساخت کانال خصوصی رسانه در تلگرام

اگه بخواید ربات عکس، ویدیو، یا صدا هم به‌عنوان پاسخ بفرسته (نه فقط متن)، این‌ها رو باید یک‌جایی بایگانی کنه. به‌جای سرویس‌های پولی، از یک کانال خصوصی تلگرام که خودتون می‌سازید استفاده می‌کنیم — کاملاً رایگان.

1. توی تلگرام، یک **کانال (Channel)** جدید بسازید (نه گروه) — از منوی تلگرام: New Channel. اسمش هرچی می‌خواید باشه (مثلاً «رسانه‌های ربات من»)، و آن رو **خصوصی (Private)** بذارید.
2. وارد همون کانال بشید → روی اسم کانال بالای صفحه بزنید → Administrators → Add Admin
3. دنبال ربات خودتون بگردید (همون یوزرنیمی که در قدم ۳ ساختید) و اضافه‌اش کنید — کافیه اجازه‌ی «Post Messages» (ارسال پیام) روشن باشه
4. یک پیام دلخواه (مثلاً یک نقطه یا «سلام») توی همون کانال بفرستید
5. برید سراغ ربات خودتون در تلگرام (همون چتی که باهاش صحبت می‌کنید) و از منوی پایین صفحه «⚙️ تنظیمات» رو بزنید
6. روی «🔗 اتصال کانال رسانه» بزنید
7. ربات ازتون می‌خواد یک پیام از همون کانال به همینجا **فوروارد (Forward)** کنید. برگردید به کانال، روی همون پیامی که فرستادید نگه دارید (لمس طولانی)، «Forward» رو بزنید، و مقصدش رو همین چت با ربات انتخاب کنید

✅ اگه پیام «🎉 کانال رسانه با موفقیت وصل شد» رو دیدید، تمومه.

---

## قدم ۱۰ — وصل‌کردن ربات تلگرام به سرور

آخرین قدم: باید به تلگرام بگیم که پیام‌های ربات‌تون رو کجا بفرسته.

1. همون آدرس Worker که در قدم ۷ کپی کردید رو دوباره پیدا کنید (شبیه `https://shemibot.YOUR-NAME.workers.dev`)
2. یک مرورگر (Chrome، Safari و...) باز کنید
3. توی نوار آدرس بالای مرورگر، این رو بچسبونید و جاهای مشخص‌شده رو با مقادیر خودتون جایگزین کنید، بعد Enter بزنید:

```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN شما>/setWebhook?url=<آدرس Worker شما>/webhook/telegram
```

مثال واقعی‌شده:
```
https://api.telegram.org/bot123456789:AAExxxxx/setWebhook?url=https://shemibot.ali.workers.dev/webhook/telegram
```

4. اگه صفحه‌ای شبیه این دیدید، یعنی موفق بودید:
```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

## تبریک! حالا امتحانش کنید 🎉

1. توی تلگرام، برید سراغ ربات خودتون (همونی که در قدم ۳ ساختید) و بزنید Start
2. باید یک پیام خوش‌آمد با چندتا دکمه پایین صفحه ببینید
3. روی «🔗 پیج‌های من» بزنید → «➕ افزودن پیج جدید» → توکنی که در قدم ۶ گرفتید رو بفرستید
4. اگه پیام «✅ پیج ... با موفقیت وصل شد» رو دیدید، همه‌چیز کار می‌کنه!
5. حالا از «💬 پاسخ هوشمند» یک کلمه‌ی کلیدی امتحانی بسازید و با یک اکانت دیگه به پیج‌تون همون کلمه رو دایرکت بدید تا پاسخ خودکار رو ببینید.
6. (اختیاری) اگه می‌خواید «فالو اجباری» رو امتحان کنید: برید «🔗 پیج‌های من» → روی پیج‌تون بزنید → «🟢 روشن‌کردن فالو اجباری» → یک متن دلخواه بفرستید. از این به بعد، قبل از پاسخ‌های اون پیج، اول دو دکمه (رفتن به پیج + فالو کردم) نشون داده می‌شه.

## اگه یه‌جایی گیر کردید

- **پیام «این ربات خصوصیه»**: یعنی عدد `ADMIN_TELEGRAM_ID` که در قدم ۷ وارد کردید، با شناسه‌ی واقعی تلگرام‌تون (قدم ۴) یکی نیست. توی تنظیمات Worker (Settings → Variables and Secrets) درستش کنید.
- **دکمه‌ی Deploy to Cloudflare کار نکرد**: مطمئن بشید در قدم ۲ واقعاً Fork رو کامل کردید و لینک دکمه به ریپوی خودِ شما (نه ریپوی اصلی) اشاره می‌کنه.
- **بعد از /start هیچ‌جوابی نمیاد**: قدم ۱۰ (وصل‌کردن وبهوک تلگرام) رو دوباره چک کنید — این رایج‌ترین فراموشیه.
- **اتصال پیج ناموفق بود**: توکنی که از قدم ۶ گرفتید احتمالاً منقضی شده (توکن‌های اولیه گاهی فقط چند ساعت اعتبار دارن) — یک توکن تازه از App Dashboard متا بگیرید و دوباره امتحان کنید.
- **«Verify and Save» توی قدم ۸ خطا می‌ده**: Callback URL باید دقیقاً با `/webhook/instagram` تموم بشه (نه بدونش)، و Verify Token باید حرف‌به‌حرف با `IG_WEBHOOK_VERIFY_TOKEN` که در قدم ۷ ست کردید یکی باشه — یک فاصله یا حرف اضافه هم باعث شکست می‌شه.
- **وبهوک تأیید شد ولی دایرکت‌ها/کامنت‌ها اصلاً به ربات نمی‌رسن**: قدم ۸ رو دوباره چک کنید — این معمولاً یعنی «Allow access to messages» توی تنظیمات خودِ اپ اینستاگرام هنوز روشن نشده.
- **عکس/ویدیو/صدا فرستاده نمی‌شه**: مطمئن بشید قدم ۹ (وصل‌کردن کانال رسانه) رو کامل کردید.
