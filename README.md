# دایرکت هوشمند اینستاگرام — متن‌باز و خودمیزبان

جایگزین رایگان و متن‌باز ManyChat برای اتوماسیون دایرکت اینستاگرام. هرکسی می‌تونه یک نمونه‌ی مستقل روی اکانت Cloudflare خودش دیپلوی کنه؛ هیچ سرویس مرکزی‌ای در کار نیست، و هیچ‌جای این پروژه نیازی به ثبت کارت بانکی ندارید. تنظیمات کاملاً از طریق دکمه‌های یک ربات تلگرامی خصوصی انجام می‌شه — بدون نیاز به تایپ هیچ دستوری.

**تازه‌کارید؟** مستقیم برید سراغ **[راهنمای نصب قدم‌به‌قدم](docs/deploy-guide-beginner.md)** — فرض شده هیچی از این فضا نمی‌دونید.

## ویژگی‌ها
- 🤖 **پاسخ هوشمند** — پاسخ خودکار به کلمه‌ی کلیدی در دایرکت (متن/عکس/ویدیو/صدا/ویترین)
- 💬 **کامنت/لایو هوشمند** — پاسخ خودکار (عمومی + دایرکت خصوصی) به کامنت زیر پست/ریلز/لایو
- 🛍 **ویترین‌ساز** — نمایش محصولات به‌شکل کارت‌های قابل‌اسکرول در دایرکت
- 🔁 **فالوآپ** — پیام پیگیری خودکار، زمان‌بندی‌شده بعد از یک رویداد
- 🔒 **فالو اجباری (اختیاری)** — قبل از ارسال پاسخ، از کاربر می‌خواد پیج رو فالو کنه؛ روشن/خاموش‌کردنش برای هر پیج جدا از داخل «🔗 پیج‌های من» انجام می‌شه. بعد از زده‌شدن دکمه‌ی «فالو کردم»، ربات با فیلد رسمی `is_user_follow_business` سعی می‌کنه واقعاً چک کنه (این فیلد در مستندات متا فقط برای مسیر قدیمی‌تر Facebook Login تأیید شده، نه لزوماً مسیر Instagram Login که این پروژه استفاده می‌کنه)؛ اگه این چک به هر دلیلی ممکن نشه، به‌جای گیرکردن کاربر، به تپ‌کردن دکمه اعتماد می‌کنه (fallback خودکار).
- 🔄 رفرش خودکار توکن هر روز — بعد از یک‌بار ستاپ، دیگه نیازی به ستاپ مجدد نیست
- 🎛 مدیریت کامل از طریق دکمه‌های شیشه‌ای و منوی پایین صفحه‌ی تلگرام (رنگی، طبق آخرین آپدیت Bot API) — بدون هیچ دستور اسلش
- 💸 **کاملاً رایگان، بدون نیاز به کارت بانکی** — روی پلن رایگان Cloudflare Workers/D1 اجرا می‌شه؛ برای بایگانی عکس/ویدیو/صدا هم به‌جای سرویس‌های پولی مثل R2، از یک کانال خصوصی تلگرام که خودتون می‌سازید استفاده می‌شه
- 🔓 بدون App Review یا Business Verification متا — هر نمونه فقط برای اکانت‌های تستر خودش کار می‌کنه (Standard Access)
- ✍️ **بدون هیچ پیام یا محتوای از‌پیش‌تعیین‌شده** — هرچی ربات می‌فرسته، دقیقاً همونیه که خودتون تنظیم کردید؛ محتوا و رعایت قوانین مربوط به پیام‌رسانی خودکار در حوزه‌ی قضایی خودتون، کاملاً بر عهده‌ی خودتونه.

## نصب
دو تا راه دارید:
- **[راهنمای قدم‌به‌قدم برای مبتدی‌ها](docs/deploy-guide-beginner.md)** — همه‌چیز از صفر، با جزئیات کامل
- نصب دستی سریع (برای کسایی که با Cloudflare/wrangler آشنان) — پایین همین صفحه

پیش‌نیاز مشترک هر دو راه: یک اپ فیسبوک دولوپرز شخصی. راهنمای فنی‌ترش: [docs/facebook-app-setup.md](docs/facebook-app-setup.md)

### نصب سریع با دکمه

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/alihashemiagenticai-ux/Shemibot)

موقع دیپلوی این مقادیر رو ازتون می‌پرسه (هر کدوم با یک توضیح کنار خودش):

| متغیر | از کجا بیارید |
|---|---|
| `TELEGRAM_BOT_TOKEN` | از [@BotFather](https://t.me/BotFather) در تلگرام |
| `FACEBOOK_APP_ID` | از App Dashboard متا — [راهنما](docs/facebook-app-setup.md) |
| `FACEBOOK_APP_SECRET` | از App Dashboard متا |
| `ADMIN_TELEGRAM_ID` | آیدی عددی تلگرام خودتون (مثلاً از [@userinfobot](https://t.me/userinfobot)) |
| `IG_WEBHOOK_VERIFY_TOKEN` | یک رشته‌ی دلخواه خودتون — همین رو موقع ثبت وبهوک اینستاگرام هم وارد می‌کنید |

آدرس خودِ Worker (`WORKER_BASE_URL`) رو دیگه نیازی نیست جایی وارد کنید — Worker خودش از روی هر درخواستی که بهش می‌رسه تشخیصش می‌ده.

بعدش:
1. یک‌بار وبهوک تلگرام رو با باز کردن این آدرس در مرورگر (بعد از جایگزین‌کردن مقادیر) فعال کنید:
   ```
   https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=<آدرس Worker شما>/webhook/telegram
   ```
2. وبهوک اینستاگرام رو در App Dashboard متا ثبت کنید (Callback URL + همون `IG_WEBHOOK_VERIFY_TOKEN`) — جزئیات کامل در [docs/facebook-app-setup.md](docs/facebook-app-setup.md).
3. در تلگرام به ربات‌تون پیام بدید، از منوی «⚙️ تنظیمات» یک کانال خصوصی تلگرام برای بایگانی رسانه وصل کنید (برای پاسخ‌های عکس/ویدیو/صدا لازمه — جزئیات کامل در راهنمای مبتدی‌ها).

### نصب دستی (جایگزین دکمه)
```bash
npm install
npx wrangler d1 create instagram-smart-direct-db
# database_id خروجی رو در wrangler.toml جایگزین 00000000-0000-0000-0000-000000000000 کنید
npm run db:migrate:remote

npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put FACEBOOK_APP_ID
npx wrangler secret put FACEBOOK_APP_SECRET
npx wrangler secret put ADMIN_TELEGRAM_ID
npx wrangler secret put IG_WEBHOOK_VERIFY_TOKEN

npm run deploy
```

## استفاده
بعد از نصب، در تلگرام به ربات‌تون `/start` بزنید. همه‌چیز از همون‌جا با دکمه پیش می‌ره:
- **🔗 پیج‌های من** — وصل‌کردن/مدیریت پیج‌های اینستاگرام
- **💬 پاسخ هوشمند** — تعریف کلمه‌ی کلیدی و پاسخ (دایرکت/کامنت)
- **🛍 ویترین** — افزودن محصول به ویترین
- **🔁 فالوآپ** — تعریف پیام پیگیری خودکار
- **⚙️ تنظیمات** — اتصال کانال خصوصی برای بایگانی عکس/ویدیو/صدا

## معماری
```
تلگرام (دکمه‌ای) ──▶ Cloudflare Worker ──▶ Cloudflare D1
                          ▲  │      │
                    Cron  │  ▼      ▼
                          Instagram   کانال خصوصی تلگرام
                          Graph API   (بایگانی رسانه — بدون R2)
```
رسانه (عکس/ویدیو/صدا) در کانال خصوصی تلگرامی که خودتون می‌سازید بایگانی می‌شه؛ وقتی اینستاگرام لازمش داشته باشه، خودِ Worker همون لحظه از تلگرام می‌گیرتش و پاس می‌ده — بدون نیاز به هیچ سرویس ذخیره‌سازی پولی یا ثبت کارت بانکی.

## وضعیت پروژه
همه‌ی ۶ فاز برنامه‌ی اصلی پیاده‌سازی شدن (پاسخ هوشمند، کامنت/لایو هوشمند، ویترین، فالوآپ، رفرش خودکار توکن، پنل تلگرامی کامل). قبل از استفاده‌ی واقعی، حتماً یک دور کامل تست دستی انجام بدید.
